# FixCell

Site criado no Micronuage.

## Como rodar

```bash
npm install
npm run dev
```

- `npm run build` — gera a versão de produção
- `npm test` — roda os testes

Feito com: React, Vite, TypeScript, Tailwind CSS, React Router.

## Pedido original

O que foi pedido quando o site foi criado na Micronuage:

> Crie um sistema web para uma assistência técnica de celulares chamada "FixCell". Deve ter login, cadastro de clientes e cadastro de ordens de serviço (aparelho, defeito, valor e status). Visual limpo e profissional.
